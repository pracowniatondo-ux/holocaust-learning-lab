# Holocaust Education — Interactive Learning Lab

A static, browser-based learning resource. No server-side code, database, analytics, cookies, student accounts or external JavaScript libraries are required.

## Files
- `index.html` — public landing page
- `tools.html` — two interactive activities: The Evidence Desk and Pause Before You Share
- `teacher-guide.txt` — teacher notes and classroom guidance
- `assets/` — reserved for project assets

The third activity, Holocaust History Timeline, links to the existing Romanian partner activity: https://interacty.me/projects/a0b7282858e866a7

## Preview locally
Open `index.html` in a modern web browser. The activities run locally as static files.

## Publish with GitHub Pages
1. Create a new public repository on GitHub (for example `holocaust-learning-lab`).
2. Upload the contents of this folder to the repository root (not the folder itself).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. GitHub Pages will provide a public URL after deployment completes.

No custom domain is required. A custom domain can be connected later if the project team has one.

## Before public release
- Have a Holocaust educator / historian review the educational content and wording.
- Confirm the project title, partner acknowledgements, logo use and required funding credits.
- Confirm permission to link to and reproduce any third-party materials.
- Review age range: the current prototypes suggest 12–14; align this with the handbook and project-wide age statement.
- Add translations only after review by a fluent educator.

## Accessibility and privacy
The activities are keyboard-operable, responsive, and do not collect student data. There is no score transmission or tracking. The current prototypes use fictional practice examples, not real archival records.
